# Keystone

Marketing site for Keystone — finance operations infrastructure (invoicing,
collections, AI phone booking, quoting, reporting) for established UK
plumbing, electrical and HVAC businesses with multiple engineers and a real
back office.

Static HTML/CSS/vanilla JS, deployed to GitHub Pages via
`.github/workflows/deploy.yml` on every push to `main`.

- `index.html` — home
- `services.html` — services
